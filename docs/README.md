## 更新の約束

実装を変えたら、該当する仕様・操作ガイド・コード参照を同じ変更で更新します。
ファイルやシンボルの追加・改名・移動は参照表にも反映し、リンク先を確認します。
コード参照はモジュール直下の定義とクラス内のメソッドを対象とし、関数内の局所関数は
親関数の実装詳細として扱います。型のフィールド・引数・戻り値はリンク先のソースを正本とします。

旧版の比較が必要なときだけ移行資料から辿り、通常の調査ではアーカイブを展開しません。

文書のローカルリンクとソース定義の網羅・行番号は、リポジトリルートで
`python3 scripts/check_documentation.py` を実行して確認できます。
説明文の意味や設定例の妥当性は実装と照合してレビューします。
